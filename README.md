# Instituto Recomeçar
## Transformando vidas

Site institucional desenvolvido para o Instituto Recomeçar, uma organização fictícia voltada ao apoio de famílias em situação de vulnerabilidade social.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Design responsivo
- Git
- GitHub

## Funcionalidades

- Página inicial institucional
- Apresentação da organização
- Seção de projetos sociais
- Área para doações e voluntariado
- Informações de contato
- Layout responsivo para dispositivos móveis
- Efeitos de interação com CSS

## Estrutura do projeto

```text
instituto-recomecar/
├── css/
│   └── style.css
├── imagens/
│   └── atendimento.JPG.jpg
├── index.html
└── README.md

## Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.

O projeto não precisa de servidor ou banco de dados para funcionar.
